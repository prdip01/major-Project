Clinical Precautions & Actions

🧬 ABCDE Clinical Self-Check Guide

Clinical rule for checking changes in common Melanocytic Nevi (Moles)

A Asymmetry split circle ▼

One half of the mole or lesion does not match the other half. Draw a line through the center; symmetrical shapes are typically benign, while asymmetric outlines require professional analysis.

B Border Irregularity wavy line ▼

The edges of the mole are irregular, ragged, notched, blurred, or poorly defined. Benign nevi have smooth, sharp, and well-demarcated circular borders.

C Color Variation color palette ▼

The color is not uniform across the mole. It may feature varying shades of brown, tan, black, or sometimes patches of red, white, or blue. Symmetrical, consistent pigment is generally safer.

D Diameter (>6mm) ruler ▼

The size of the spot is larger than 6 millimeters across (roughly the size of a standard pencil eraser), although melanomas can sometimes be smaller when initially detected.

E Evolution & Change clock / arrow ▼

The mole is changing in size, shape, color, or height. It may also develop new symptoms such as itching, bleeding, crusting, or oozing. Evolution over time is the most critical warning sign for malignancy.

E. Class Weights & Imbalance Handling

Preventing the model from ignoring rare disease classes

HAM10000 is heavily skewed toward Melanocytic Nevi (NV) (~67%). If unweighted, the classifier could maximize simple accuracy by defaulting every output to NV, producing massive false negatives for critical classes like Melanoma.

Disease Code Diagnostic Name Computed Class Weight
nv Melanocytic Nevi 0.21 (Suppressed)
mel Melanoma 1.28
bkl Benign Keratosis 1.30
bcc Basal Cell Carcinoma 2.78
akiec Actinic Keratoses 4.37
vasc Vascular Lesions 10.07 (Boosted)
df Dermatofibroma 12.44 (Boosted)
Weight Equation Formulation (sklearn balanced) Weight = N_samples / (N_classes * N_class_samples)

⚠️

Academic System Limitations

Honest laboratory disclosures regarding medical classification bounds

  1. Not FDA/CE Certified: This software is strictly for academic research and is not certified for clinical diagnostic decisions.
  2. Image Quality Requirements: Outputs depend heavily on dermoscopy-quality, clean, macro-focused scans. Poor lighting or standard mobile photos produce high error rates.
  3. Closed 7-Class Vocabulary: The model functions as a closed classifier for the HAM10000 labels. It cannot diagnose rare lesions outside these categories.
  4. Class Imbalance Sensitivity: Though training weights are heavily optimized, classification accuracy for rare nodes remains subject to dataset representation limitations.
  5. No Substitute for Biopsy: A biopsy and expert histopathological review remain the gold standard in dermatology. Under no circumstances should output probabilities delay professional consultation.

System Specifications & Parameters

DermaDrishti maps out disease weights by passing preprocessed inputs through an EfficientNet-B0 deep convolutional network trained on 10,015 images. Intermediary convolutional nodes generate spatial activations, which are blended with raw dermoscopy views using cv2 linear interpolations.

Research Gap & Our Contribution

Problems identified in existing literature and how DermaDrishti addresses them

GAP 1: Black-Box Models

Existing systems — including Esteva (Inception-v3) and Han (ResNet-50) — produce diagnostic predictions without any visual explanation of why the classification was made, making clinical validation impossible.

→ OUR FIX: Integrated Grad-CAM with a draggable comparison slider that visually highlights exact neural activation regions on the scan.
GAP 2: No Clinical Guidance

Users receive a raw diagnostic label (e.g. "Melanoma") with no next-step instructions. This is critically dangerous for a layperson who may misinterpret results without medical context.

→ OUR FIX: Per-class precautions with severity indicators and an ABCDE self-monitoring accordion guide displayed automatically for borderline benign cases (nv).
GAP 3: Cloud-Dependent & Expensive

Commercial platforms (DermEngine, Skinive) require internet connectivity, paid subscriptions, and upload of sensitive skin images to remote servers — raising privacy and accessibility concerns.

→ OUR FIX: Fully offline-capable with localStorage-backed SQLite session history, lightweight EfficientNetB0 (5.3M params), PDF report export, and zero subscription cost.
🟢
OUR NOVEL CONTRIBUTION

"First academic skin lesion classifier to combine real-time Grad-CAM explainability, educational ABCDE self-check guidance, session-based local SQLite history, and one-click clinical PDF export in a single lightweight open-source web application."

Project Overview

A full-stack deep learning application for automated classification of dermatoscopic skin lesions into 7 diagnostic categories using transfer-learned EfficientNetB0 on the HAM10000 dataset. The system integrates Grad-CAM explainability, clinical precaution guidance, session history, and PDF reporting in a single responsive web application.

DomainMedical AI / Computer Vision
LanguagePython 3.11, JavaScript ES6+
FrameworkFlask, TensorFlow/Keras, Chart.js
DatasetHAM10000 (10,015 images)
ModelEfficientNetB0 (5.3M parameters)
Input224×224 RGB dermoscopy image
OutputPredicted class + confidence + Grad-CAM
LicenseCC BY-NC 4.0 (Academic Use)

Database Schema

DermaDrishti uses SQLite for local persistence. The database file is backend/derma_history.db. No sensitive patient data or image buffers are stored.

Table: predictions
ColumnTypeConstraintDescription
idTEXTPRIMARY KEYUUID v4 generated per prediction
timestampTEXTNOT NULLISO 8601 prediction datetime
predicted_classTEXTNOT NULLShort class code: mel, nv, bcc, etc.
full_nameTEXTHuman-readable disease name
confidenceREALSoftmax confidence percentage (0–100)
is_cancerINTEGERBoolean flag: 1 = malignant, 0 = benign
binary_resultTEXT"Cancer" or "Non-Cancer" label
colorTEXTHex color code for UI display
probabilitiesTEXTJSON string of all 7 class probabilities
precautionsTEXTJSON array of clinical precaution strings
🔒

Privacy Note: Images are processed entirely in-memory and immediately discarded after inference. No pixel data is written to disk or the database at any time.

User Manual

📤

Step 1: Upload a Dermoscopic Image

Navigate to the Analyze Scan section. Drag & drop a JPG/PNG skin lesion image onto the upload zone, or click Browse Files. You may also paste an image from clipboard (Ctrl+V). Accepted formats: JPEG, JPG, PNG. Maximum file size: 10MB.

📸 Drop Zone — shows image preview thumbnail with filename and file size after upload
⚡

Step 2: Execute Classification

Click the Execute Classification button (enabled only when an image is selected and the AI model is loaded). A full-screen pipeline overlay appears showing 4 stages: Input → Preprocess → CNN Model → Classify. Each step animates with a progress bar and live status subtitle.

📸 Pipeline Overlay — 4-column full-screen animation showing each processing stage
🔬

Step 3: Interpret the Results

After inference completes, the Results section appears. It contains: (a) a BENIGN/MALIGNANT badge with confidence percentage in a radial gauge, (b) a Grad-CAM draggable slider comparing the raw dermoscopy scan to the neural activation heatmap, and (c) a probability bar chart for all 7 classes.

📸 Results — BENIGN/MALIGNANT badge, radial confidence gauge, Grad-CAM slider, Chart.js probability chart
🧬

Step 4: ABCDE Self-Check Guide

If the predicted class is Melanocytic Nevi (nv) — the most common borderline case — an interactive ABCDE accordion guide appears automatically. Each letter (Asymmetry, Border, Color, Diameter, Evolution) expands to reveal clinical self-monitoring criteria.

📸 ABCDE Guide — expandable accordion, visible only for nv class predictions
📋

Step 5: View Session History

Scroll to Registry Log. All predictions in the current session are listed chronologically with class name, confidence match %, BENIGN/MALIGNANT badge, and timestamp. Click any row to expand full details and re-download the PDF report.

📸 Registry Log — expandable history rows with colored dot indicators
📄

Step 6: Download PDF Report

Click 📄 Download PDF Report in the Results section. A clinical-grade PDF is generated client-side using jsPDF containing: scan UUID, timestamp, diagnosis, confidence, probability table, precautions, and medical disclaimer.

📸 PDF Report — A4 portrait, dark header with DermaDrishti branding, probability table, disclaimer block

Future Enhancements

The following roadmap items are identified for future development cycles beyond the academic submission scope.

🔮

Real-Time Webcam Capture

Integrate browser MediaDevices API to capture dermoscopic images directly from connected USB dermatoscopes or mobile cameras, eliminating the file upload step.

📱

Mobile App (React Native / Flutter)

Port the frontend to a cross-platform mobile application with offline TFLite inference, enabling field use without a server dependency.

🤖

Multi-Model Ensemble

Combine EfficientNetB0 + ResNet50 + DenseNet121 predictions via soft voting ensemble to improve robustness and reduce false negatives for malignant classes.

🏥

FHIR Compliance & EMR Integration

Implement HL7 FHIR-compliant data models for clinical-grade deployment and integration with hospital Electronic Medical Record systems.

🌏

Multi-Language Support

Add localization for Hindi, Tamil, Bengali, and other regional Indian languages to make the tool accessible in rural healthcare settings.

📊

Federated Learning Architecture

Implement privacy-preserving federated learning across multiple hospital nodes so the model can improve continuously without centralizing patient data.
